## Start with a few lines

```bash
bun add git@github.com:rikhoffbauer/mvsep-client.git
```

```ts
import { MvsepClient, fileBlobFromPath } from '@rikhoffbauer/mvsep-client';

const client = new MvsepClient({ apiKeys: process.env.MVSEP_API_KEY });
const result = await client.createAndWait({
  audiofile: await fileBlobFromPath('song.wav', 'audio/wav'),
  sepType: 20, // example algorithm ID — discover current IDs at runtime
});

const manifest = await client.downloadSeparationOutputs(result, './stems');
console.log(manifest.files);
```

The SDK is not affiliated with MVSep. Creating some jobs or using premium mirror modes can consume paid credits; see [credit safety](/mvsep-client/guides/credits/).
